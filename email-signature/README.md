# Email signature generator

A standalone browser tool for preparing and copying an email signature.

## Use

Open [index.html](index.html) in a browser, enter the signature details, and use the tool's copy action. No package installation or build step is needed.

## Maintain

Edit `index.html` here. This is the public source of the shared generator. The repository's GitHub Pages deployment uses the existing `email-signature/` path.

Selected case studies belong in [Portfolio](https://github.com/Un-Ragazzo/Portfolio) and can link here to the working tool. Hosting and actual URL availability must be checked separately from source changes.
