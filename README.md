## What belongs here

- Small tools and utilities that others can try or reuse.
- Experiments, UI prototypes, demos, code samples, templates, and reference resources worth sharing.
- Work in progress when its purpose, setup, and limitations are clear.

Keep each runnable item's source, assets, and instructions together in a directory such as `email-signature/`. A single self-contained resource can stay as one file. Add structure when there is actual content to organize.

[Portfolio](https://github.com/Un-Ragazzo/Portfolio) holds selected product, UX, and design case studies explaining the problem, contribution, decisions, and outcomes. A case study can link here to its tool or demo; it does not need a second editable copy of the source.

## Public sharing

Review material before publishing and remove private, company, client, credential, and internal-context information. Private work stays in its original workspace; publish only the material that can be shared. Do not automatically sync public changes back into private workspaces.

## Hosting

GitHub Pages is enabled on this repository. The email signature generator remains at `email-signature/index.html`, and `.nojekyll` is preserved. Its public source is maintained here.

The repository is now named `Open-Workbench`. Renaming a repository does not guarantee redirects for its GitHub Pages project URLs. Verify the deployed URL and existing links before sharing a new address. Adding source here does not by itself establish a live deployment for every item.
